# Karri Satish Reddy Portfolio

Static responsive website. Before publishing, replace `YOUR-DOMAIN.example` in `sitemap.xml` and add locally hosted photos in place of the clearly labelled photo/image slots. There are no online photos in this site.

The WhatsApp number, phone, email, professional journey, testimonials and resources are all straightforward text blocks in `index.html` so they can be updated without a build system. The enquiry form currently validates in the browser and shows a confirmation; connect it to a secure form provider or backend before relying on it for live lead collection.
